# Selector contract

_Generated by `node scripts/extract-selectors.js`. Do not edit by hand._

**Audience:** mobile and web developers. Every element the automation touches is addressed by a stable test ID.

- **Mobile:** set `testID` (React Native), `Key` / `Semantics(identifier:)` (Flutter), or `accessibilityIdentifier` / `resource-id` (native) to the exact ID below. `{i}` means a zero-based index; `{x}` means the value named.
- **Inline errors** use the input's ID plus `.error`, for example `rwin.booking.deposit.input.error`.
- **Admin web:** add `data-testid`. Buttons, menu items, tabs and dialogs are located by accessible role and name taken from the PRD action names, so keep those labels in sync with the PRD.
